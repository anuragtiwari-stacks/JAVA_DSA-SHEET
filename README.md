# JAVA DSA SHEET 🚀

A well-structured **Java Data Structures & Algorithms (DSA) practice repository**, organized topic‑wise for revision, interviews, and competitive programming.

This repo contains **clean Java implementations** of common DSA problems, grouped by concept, following a progressive learning path.

---

## 📂 Folder Structure

```text
src/
├── _1ARRAY_1D            → 1D Array problems
├── _2ARRAY_2D            → 2D Matrix problems
├── _3STRING              → String algorithms
├── _4LinkedList          → Singly / Doubly Linked List
├── _5StackQueue          → Stack & Queue problems
├── _6BinaryTree          → Binary Tree traversals & problems
├── _7BinarySearchTree    → BST operations & questions
├── _8Heap_Hashing        → Heap (PriorityQueue) & Hashing
├── _9SearchingSorting    → Searching & Sorting algorithms
├── _10Tries              → Trie data structure
├── _11SegmentTree        → Segment Tree problems
├── _12Graph              → Graph algorithms (BFS, DFS, etc.)
├── _13DP                 → Dynamic Programming
├── _14Greedy             → Greedy algorithms
├── _15Backtracking       → Backtracking problems
```
